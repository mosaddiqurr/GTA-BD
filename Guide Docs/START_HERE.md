# Bangladesh Open World Project — Latest Complete Package (v0.4)

Date: 30 October 2026

## Contents
- `Bangladesh_Open_World_Complete_Blueprint_v0.4.docx`: updated consolidated editable Word blueprint.
- `documents/`: individual, up-to-date Markdown documents (project vision, PRD, GDD, art, NPC rules, audio, architecture, roadmap, licensing, research permissions and development prompts).
- `character_and_asset_reference_sheets/`: nine illustrated PNG design-reference sheets (S01–S09). S03 is the updated mixed-fruit Bangladesh male NPC design.
- `AGENTS.md` and `CLAUDE.md`: project-root instructions for Codex and Claude.

## Important constraints
- The immediate first build is a browser-based Mirpur 10 walking prototype, not the entire city.
- The playable hero can be mango. NPCs must feature different fruit species and culturally suitable clothes/accessories. Headphones are not a default accessory.
- No eyes, noses or mouths on fruit characters. No weapons, combat or fighting.
- No extra paid tools or API bills. Existing AI subscriptions are assumed.
- Future expansion can include other Dhaka neighborhoods, Cox's Bazar, Saint Martin's Island and other regions.

## How to start
1. Read `documents/00_README_START_HERE.md` and `documents/10_AI_Agent_Project_Constitution.md`.
2. Copy `AGENTS.md` and `CLAUDE.md` into the actual game project root.
3. Give the coding agent `documents/11_Codex_Claude_First_Build_Prompt.md` plus sheets S01, S02, S04 and S08 for the initial walking prototype.
4. Give S03 when beginning NPC work.

## Important reference-sheet limitation
The PNG reference boards are illustrative AI-generated **concepts**, not verified architectural blueprints, working Blender files or licensed game assets. Small Bangla labels and details may be incorrect. Verify buildings/places against properly sourced real-world references. Build final meshes in Blender, then validate their browser-ready GLB exports.
